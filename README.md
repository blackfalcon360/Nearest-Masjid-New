# Nearest Masjid

آپ کی موجودہ جگہ سے قریب ترین مسجد کا فاصلہ اور سمت دکھاتی ہے۔

## ایپ کیا کرتی ہے
- بڑا کارڈ: قریب ترین مسجد کا نام، فاصلہ (m/km)، سمت اور گھومتا ہوا تیر۔
- نیچے قریب ترین 100 تک مساجد، فاصلے کی ترتیب سے؛ کسی مسجد پر ٹیپ کریں تو نقشے کی ایپس کی فہرست کھلتی ہے اور اپنی پسند کی ایپ چن سکتے ہیں۔
- "نقشے کی ایپ میں تمام قریبی مساجد" بٹن: Google Maps (یا کوئی اور نقشے کی ایپ) میں "mosque" کی تلاش آپ کے مقام کے گرد کھول دیتا ہے، بالکل ویسے جیسے وہاں nearby mosques ٹائپ کرنے پر آتا ہے۔
- اختیاری: سیٹنگز میں اپنی Google Places API کی ڈالیں تو ایپ کی فہرست میں بھی Google کی 20 قریب ترین مساجد شامل ہو جاتی ہیں (کی کے لیے Google Cloud میں بلنگ ضروری ہے اور فیس آپ کے اکاؤنٹ پر لگ سکتی ہے)۔
- مساجد کا ڈیٹا OpenStreetMap سے آتا ہے (نئے علاقے میں خود، یا "ریفریش" بٹن) اور فون میں محفوظ رہتا ہے، پھر اسی علاقے میں بغیر انٹرنیٹ بھی چلتا ہے۔
- زبان: اردو / English / العربية؛ لائٹ اور ڈارک موڈ؛ باہر نکلنے سے پہلے تصدیق۔

## بِلڈ
1. فولڈر GitHub پر اپ لوڈ کریں۔
2. Actions میں "Build APK" چلے گا۔
3. Artifacts سے `NearestMasjid-APK` ڈاؤن لوڈ کریں۔

## پابندیاں
- صرف portrait؛ AndroidX یا بیرونی لائبریری نہیں۔
- کسی علاقے میں پہلی بار انٹرنیٹ لازمی ہے؛ بغیر انٹرنیٹ صرف پہلے محفوظ کیا ہوا علاقہ چلے گا۔
- فاصلہ سیدھی لکیر میں ہے، راستے کا نہیں۔
- ایپ کی اپنی فہرست OpenStreetMap سے ہے جو پاکستان میں Google Maps سے کم مکمل ہو سکتی ہے؛ مکمل نتیجہ کے لیے اوپر والا بٹن یا Google کی استعمال کریں۔ OpenStreetMap رضاکاروں کا بنایا ہوا ہے؛ کچھ مساجد درج نہ ہوں یا بے نام ہوں تو ممکن ہے۔
- ڈاؤن لوڈ کے وقت آپ کا مقام OpenStreetMap کے سرور کو جاتا ہے؛ سیٹنگز میں خودکار ڈاؤن لوڈ بند ہو سکتا ہے۔
